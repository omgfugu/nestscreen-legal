# Удаление данных

Вы можете удалить все локальные данные в приложении: «Ещё» → «Данные» → «Удалить все данные».

Для удаления облачного аккаунта отправьте запрос на privacy@nestscreen.app с email, указанным при регистрации. Запрос обрабатывается в течение 30 дней.

Устройство ребёнка можно отвязать в приложении родителя (удалить устройство из семьи) или переустановкой приложения.
